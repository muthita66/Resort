# ระบบการเข้าพักรีสอร์ท (Google Apps Script)

ฐานข้อมูล: Google Sheets ID `1o4GHJOk26kforQLH2yVe3qyksV3A5tmu3_4kYqSDTrU` (ตั้งค่าที่ `SPREADSHEET_ID` ใน `Code.gs`)

## วิธีติดตั้ง
1. ไปที่ https://script.google.com → **โปรเจ็กต์ใหม่** ตั้งชื่อ "ระบบการเข้าพักรีสอร์ท"
2. วางโค้ด `Code.gs` ทับไฟล์ `Code.gs`
3. กด **+ → HTML** สร้างไฟล์ชื่อ `Index` แล้ววางโค้ดจาก `Index.html`
4. **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป** แล้วกดอนุญาตสิทธิ์เข้าถึง Google Sheets และเปิดลิงก์ที่ได้

บัญชีที่ deploy ต้องมีสิทธิ์แก้ไข Google Sheet ตัวนี้ และในชีทต้องมีแท็บ `รายชื่อพนักงาน`, `ฐานข้อมูลรายการห้องพัก`, `DB_CheckIn`

## โครงสร้างข้อมูล
| ชีท | ช่วงข้อมูล |
|---|---|
| รายชื่อพนักงาน | D3:D ชื่อพนักงาน |
| ฐานข้อมูลรายการห้องพัก | A4:A ประเภทห้อง (D, T, N, P, L, G, …), B4:B เลขห้อง |

ประเภทห้องอ่านจากชีทแบบไดนามิก: เพิ่มแถวใหม่ในชีทแล้วปุ่มประเภท/เลขห้องจะแสดงเอง

## คอลัมน์ที่บันทึกใน DB_CheckIn (เริ่มแถว 3)
| คอลัมน์ | ข้อมูล |
|---|---|
| A | ประทับเวลา |
| B | ชื่อผู้รับผิดชอบ |
| D | ประเภทลูกค้า (ว่างถ้างดให้บริการ) |
| E | ประเภทห้อง |
| F | เลขห้อง |
| G | วันที่ Check in |
| H | วันที่ Check out |
| I | จำนวนคืน |
| J | สถานะห้อง (`งดให้บริการ` หรือประเภทลูกค้า) |

เปลี่ยนตำแหน่งคอลัมน์ได้ที่ตัวแปร `COL` ใน `Code.gs`

## หน้าที่ 2 แดชบอร์ด
- **สรุปรายวัน**: เลือกวันที่ → ยอดเข้าพัก / Check in / Check out / งดให้บริการ / ห้องว่าง / อัตราเข้าพัก แยกตามประเภทบ้าน และแยกตามประเภทลูกค้า
- **สรุปรายเดือน**: เลือกเดือน → จำนวนการจอง (นับตามวัน Check in), คืนที่เข้าพัก, คืนงดให้บริการ, อัตราเข้าพัก แยกตามประเภทบ้าน และประเภทลูกค้า

## หน้าที่ 3 ตรวจสอบการเข้าพัก
- **ประวัติการจองบ้านพัก**: กรองตามเดือน / ค้นหา และปุ่ม **ลบ** ซึ่งจะลบแถวนั้นออกจาก `DB_CheckIn` (ระบบตรวจว่าแถวยังเป็นรายการเดิมก่อนลบ)
- **ตารางการเข้าพัก**: ตารางห้อง × วันในเดือน ระบายสีตามสถานะ ชี้ที่ช่องเพื่อดูรายละเอียด


ผมแก้โค้ดตามที่ขอแล้วครับ ตอนนี้แอป Apps Script มี 2 ไฟล์คือ Code.gs และ Index.html ชื่อแอปเป็น "ระบบการเข้าพักรีสอร์ท" และเชื่อมกับ Google Sheets ID 1o4GHJOk26kforQLH2yVe3qyksV3A5tmu3_4kYqSDTrU

สิ่งที่เปลี่ยน:

Code.gs เปิดชีทด้วย SpreadsheetApp.openById(SPREADSHEET_ID) แล้ว จึงสร้างเป็นโปรเจกต์ Apps Script แยก ไม่ต้องผูกกับชีทก็ได้ ถ้าเปลี่ยนชีทภายหลัง ให้แก้ค่า SPREADSHEET_ID ที่บรรทัดบนของไฟล์
เปลี่ยนชื่อไฟล์ index.html เป็น Index.html ให้ตรงกับในโค้ด
เปลี่ยนชื่อในหัวหน้าเว็บและแท็บเบราว์เซอร์เป็น "ระบบการเข้าพักรีสอร์ท"
ทุกหน้าที่ทำไว้ยังอยู่ครบ คือ บันทึกการจอง, แดชบอร์ด และตรวจสอบการเข้าพัก

ผมทดสอบกับชีทจำลองแล้วทำงานได้ แต่ยังไม่ได้ทดสอบกับ Google Sheet จริง

วิธีติดตั้ง:

ไปที่ https://script.google.com แล้วกด โปรเจ็กต์ใหม่ ตั้งชื่อว่า "ระบบการเข้าพักรีสอร์ท"
วางโค้ดจาก Code.gs ทับโค้ดเดิมในไฟล์ Code.gs
กด + → HTML ตั้งชื่อไฟล์ว่า Index (ไม่ต้องพิมพ์ .html) แล้ววางโค้ดจาก Index.html
กด การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป → ทำให้ใช้งานได้ แล้วกดอนุญาตสิทธิ์เข้าถึง Google Sheets

ข้อกำหนดของชีท:

บัญชีที่ใช้ deploy ต้องมีสิทธิ์แก้ไขชีทนี้
ในชีทต้องมีแท็บชื่อ รายชื่อพนักงาน, ฐานข้อมูลรายการห้องพัก และ DB_CheckIn โดยสะกดให้ตรงทุกตัวอักษร
